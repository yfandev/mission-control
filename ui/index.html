Buttons send POST requests with no body to trigger chaos workflows in local runtime:

  • POST /chaos/supplier: Supplier failure triggers multi-agent procurement DAG rerouting.
  • POST /chaos/coldchain: Reefer temperature alert (+4.2°C) requiring emergency re-routing.
  • POST /chaos/surge: Influx of 5 customer inquiries processed in parallel.
  • POST /chaos/inject: Prompt injection attack quarantined by Sentinel policy.
  • POST /chaos/pause: Pause / resume the event stream.

When an action exceeds risk/dollar threshold (e.g. procurement lease > $10,000), an approval card appears:

POST /approve/:id -> Confirms execution of risky tool call POST /deny/:id -> Cancels tool call and triggers fallback escalation
